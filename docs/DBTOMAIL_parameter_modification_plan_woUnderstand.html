1. アーキテクチャおよび処理フローの概要

DBTOMAIL コマンドは、CLコマンド定義を起点にC言語のコマンド処理プログラム（CPP）が起動し、一時IFSストリームファイルの生成・メール送信サービス（SMTPSRVS）との連携を行います。

実行ステップの詳細:

  1. コマンド実行: ユーザーが DBTOMAIL コマンドを実行し、宛先やファイル、追加されるファイル形式（FMT）などを指定。
  2. パラメータ解析: CPP（DBTOMAIL.C）が argv を解析し、添付ファイル名・一時ストリームファイル名を決定。
  3. データ変換: DBTOCSV.CLP およびRPGプログラムがデータベースファイルから指定形式へデータを変換し一時IFSファイルへ出力。
  4. 送信と削除: SMTPSRVS サービスプログラムがIFSファイルをMIME添付してSMTP送信し、送信完了後に一時ファイルを削除。

3. 詳細な修正内容と設計上の考慮点

(1) コマンド定義 (DBTOMAIL.CMD)

  • パラメータ定義の追加: 
    PARM       KWD(FMT) TYPE(*CHAR) LEN(10) RSTD(*YES) DFT(*CSV) +
             VALUES(*CSV *TXT *TSV) +
             PROMPT(DBT0220 75)
  • パラメータ順序に関する注意:
    ⚠️ 引数順序 (argv) の整合性
    IBM i の CL コマンドでは、CPP（Cプログラム）へ渡される argv の順番は CMD ソース内の PARM 定義順 に依存します。
    既存の位置に挿入すると、それ以降のすべてのパラメータの argv[n] のインデックスがずれるため、DBTOMAIL.C の memcpy 箇所をすべて合わせて更新する必要があります。末尾（argv[21]）に追加する場合は既存パラメータへの影響を最小限に抑えられます。

(2) コマンド処理プログラム (DBTOMAIL.C)

  • 引数受取と変数宣言:

    ファイル形式用変数（例: char PFMT[11]={0};）を追加し、main 関数内で argv から値を取得します。

  • 添付ファイル拡張子の動的判定:

    現状は PATNAME が *FILE の場合に無条件で .csv を付与していますが、形式パラメータに応じて拡張子を動的に切り替えます。

    if(PATNAME[0] == '*'){
    memcpy(wAtname, PFILE, 10);
    for(i = 0; i < 31; i++){
        if(wAtname[i] <= ' '){
            if(strncmp(PFMT, "*TXT", 4) == 0){
                memcpy(&wAtname[i], ".txt", 5);
            } else if(strncmp(PFMT, "*TSV", 4) == 0){
                memcpy(&wAtname[i], ".tsv", 5);
            } else {
                memcpy(&wAtname[i], ".csv", 5);
            }
            break;
        }
    }
}
  • 変換呼び出し・分岐:

    DBTOCSV(...) 呼出に対してパラメータを渡すか、ファイル形式ごとに呼び出すプログラムを分岐させます。

  • MIMEタイプの指定（推奨）:

    SMTPMpartAttach で、形式に応じた適切な Content-Type（text/csv, text/plain, text/tab-separated-values 等）を設定できるようにします。

(3) 変換処理群 (DBTOCSV.CLP, DBTOCSVR.RPGLE)

  • *TXT（固定長）の場合: 区切り文字なしでそのままコピー（CPYTOSTMF などの利用）。
  • *TSV（タブ区切り）の場合: 区切り文字をカンマから 0x05（EBCDICタブ）または変換時にタブへ切り替え。
  • DBTOCSV.CLP のパラメータ追加に伴い、PGM PARM(...) および DBTOCSVL/DBTOCSVR との連携を拡張します。

(4) メッセージファイルおよびヘルプ

  • ADBMSG.CLP: プロンプト文言用（例: DBT0220 -> 'ファイル形式:'）の ADDMSGD コマンドを追加し実行。
  • DBTOMAIL.PNLGRP: パラメータ FMT のヘルプセクションと有効値の説明を追加。

4. 考慮事項および推奨テスト手順

  • CCSID・文字コード変換の整合性: FROMCCSID（EBCDIC）から TOCCSID（SJIS: 943, UTF-8: 1208等）への変換が各形式で正しく適用されることを確認します。
  • バイナリ/MIMEタイプ: 現行は application/octet-stream で汎用送信されていますが、必要に応じて text/plain や text/csv への切り替えを検討します。
  • 単体テスト項目:
    1. 形式無指定時のデフォルト（*CSV）動作の既存互換性確認
    2. FMT(*TXT) 指定時の固定長テキスト出力および添付名（.txt）確認
    3. FMT(*TSV) 指定時のタブ区切り出力確認
    4. ATFILE 明示指定時とデフォルト（*FILE）時の拡張子処理確認
