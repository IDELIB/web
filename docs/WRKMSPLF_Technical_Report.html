WRKMSPLF UIM アクションリスト出口プログラム実装 技術知見レポート

対象システム: IBM i (bluenote) / OS Version: 7.5 | プロジェクト: MAI/400 (V3.00) | 作成日: 2026/03/27

1. 概要と背景課題

WRKMSPLF コマンドは、UIM パネルグループのリスト機能（ACTOR=UIM）を用いてスプールファイル一覧を表示しています。

従来の課題
ACTOR=UIM 配下の :LISTACT で CL コマンド（HLDSPLF, RLSSPLF, CHGSPLFA, DLTSPLF 等）を実行した場合、UIM は RPG 側に制御を戻さずに UIM 内部の再表示ルーチンで画面を再描画するため、画面上のリスト行ステータス（STS）や削除行が最新化されない問題が発生していました。

この問題を解決するため、UIM 標準のアクションリスト出口プログラム（USREXIT）機構を採用し、コマンド実行完了直後に UIM リストエントリを動的に更新・削除する仕組みを実装しました。

3. 技術的知見とトラブルシューティング

① アクションリスト出口プログラムのインターフェース仕様

UIM から USREXIT='CALL EXITPGM' 経由で呼び出される出口プログラムには、QSYSINC/QRPGLESRC/EUIALEX（または H/EUIALEX.C）で定義された 70バイトのパラメータ構造体（CallType = 5）が渡されます。

オフセット フィールド名 データ型 説明
1〜4 StrucLevel BINARY(4) 構造体レベル
5〜12 Reserv1 CHAR(8) 予約領域
13〜16 CallType BINARY(4) 5（アクションリスト出口）
17〜24 ApplHandle CHAR(8) UIM アプリケーション・ハンドル
25〜34 PanelName CHAR(10) パネル名（MAINPNL）
35〜44 ListName CHAR(10) リスト名（SPLFLIST）
45〜48 ListEntry CHAR(4) 対象エントリのハンドル
49〜52 ListOption BINARY(4) 実行されたオプション番号（2=変更, 3=保留, 4=削除, 6=解放 等）
53〜56 FuncQualifier BINARY(4) 0=実行キー, 1=プロンプト(F4)
57〜60 Result BINARY(4) 0=コマンド成功, 0以外=エラー
61〜70 FieldName CHAR(10) フィールド名

② エラー CPF6A98 の発生と QUSRTOOL（T0011）による解決

開発初期に QUIGETLE API の位置づけオプションに posOption = 'HNDL' を指定した際、CPF6A98（リストに対象項目が見つからない） が発生しました。

知見: UIM カレントエントリポインタの特性
USREXIT が呼び出された時点で、UIM 内部のカレントエントリポインタは 既に該当のアクション実行行に位置づけられています。
そのため、QUSRTOOL/QATTRPG/T0011RA5 の実装パターンに倣い、posOption = 'SAME'（カレントエントリ直接取得）および updOption = 'SAME'（カレントエントリ更新）を指定することで、ハンドル不一致エラーを完全に排除して安全に更新できるようになりました。

③ ステータス（STS）カラムの 4 桁表示拡張

オプション実行直後にユーザーへ視覚的なフィードバックを与えるため、STS 欄にアスタリスク付きのステータス（*HLD, *CHG, *RLS）を表示する要件がありました。
従来の MAXWIDTH=3 では 3 文字で切り詰められてしまうため、パネルグループ定義を MAXWIDTH=4 に拡張しました。 

:LISTCOL  VAR=STS
          USAGE=OUT
          MAXWIDTH=4
          HELP='WRKMSPLF/HSTS'.
STS

4. 出口プログラム（WRKMSPLFX）のコアロジック

**free
// ---------------------------------------------------------------
// PROGRAM-ID    : WRKMSPLFX
// REMARKS       : WRKMSPLF UIM Action List Exit Program
// ---------------------------------------------------------------
ctl-opt dftactgrp(*no) actgrp(*caller) option(*srcstmt);

// (API プロトタイプ・データ構造定義省略)

dcl-pi *n;
  p_exitParms char(70);
end-pi;

exitParms = p_exitParms;

// コマンド実行が成功 (result = 0) の場合のみ処理
if result <> 0;
  *inlr = *on;
  return;
endif;

leHndl = listEntry;

// オプション 4 (削除): リストからエントリを削除
if listOption = 4;
  errDs.bytesAvail = 0;
  QUIRMVLE( applHandle : listName : 'N' : leHndl : errDs );
  *inlr = *on;
  return;
endif;

// オプション 2(変更), 3(保留), 6(解放) 等: カレントエントリを取得して属性更新
errDs.bytesAvail = 0;
clear uimEntry;
QUIGETLE( applHandle
        : uimEntry
        : %size(uimEntry)
        : 'SPLFENT   '
        : listName
        : 'SAME'          // ★ カレント行を直接取得
        : 'N'
        : '*NONE     '
        : *allx'00'
        : 'N'
        : leHndl
        : errDs );

if errDs.bytesAvail > 0;
  *inlr = *on;
  return;
endif;

// オプション実行直後の STS 表示制御
select;
  when listOption = 2;
    uie_sts = '*CHG';
  when listOption = 3;
    uie_sts = '*HLD';
  when listOption = 6;
    uie_sts = '*RLS';
endsl;

// リストエントリをインプレース更新
errDs.bytesAvail = 0;
QUIUPDLE( applHandle
        : uimEntry
        : %size(uimEntry)
        : 'SPLFENT   '
        : listName
        : 'SAME'          // ★ カレント行を更新
        : leHndl
        : errDs );

*inlr = *on;
return;
