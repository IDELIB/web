1. 概要

MAI/400 は IBM i の National Language Support (NLS) 機構を利用して、 ユーザーのジョブ CCSID（言語設定）に応じたコマンドプロンプト・ヘルプ・メッセージを 自動的に切り替えます。
各言語用のプロダクションライブラリに、コマンド (*CMD)、ヘルプパネルグループ (*PNLGRP)、メッセージファイル (*MSGF) が格納されています。

ライブラリリストへの組み込み方: ユーザーの言語に対応するライブラリを *LIBL の先頭（または MAI の前） に追加することで、自動的に各言語のオブジェクトが優先参照されます。 例: ADDLIBLE LIB(MAI2928) POSITION(*FIRST)（フランス語ユーザーの場合）

3. IBM i NLS 機構とライブラリリスト

1. ジョブ言語 ジョブの LANGID / CCSID がユーザーの言語環境を決定する。
2. ライブラリリスト 該当言語のライブラリ（例: MAI2929）をライブラリリストの MAI より前に追加する。
3. 自動選択 コマンド呼び出し時、IBM i は *LIBL を先頭から検索し、最初に見つかった *CMD / *PNLGRP / *MSGF を使用する。
4. フォールバック 言語ライブラリにオブジェクトが存在しない場合は、MAI（日本語ベース）の オブジェクトが使用される。

ライブラリリスト設定例

ドイツ語ユーザー向けのジョブ初期化例 (CL):

/* ドイツ語ライブラリを MAI より前に追加 */
ADDLIBLE  LIB(MAI2929) POSITION(*BEFORE MAI)

6. 備考・注意事項

  • MAI2924 (English) は他言語ライブラリより多くのオブジェクトを含む。 SPLTOPDF コマンド・パネルグループ、WRKMSPLFX プログラム、 QPNLSRC / QRPGLESRC ソースファイル、MAIPMT メッセージファイル は MAI2924 固有オブジェクト。他言語ライブラリに存在しない場合は MAI が使用される。
  • MAI2932 (Italian) には DBTOCSV と SPLTOPDF コマンドが含まれており、 他言語ライブラリ (MAI2928/29/31) には存在しない。
  • WRKMSPLF コマンド・パネルグループ は今回 (2026-09-27) に全 NLS ライブラリへ追加された。
  • QPNLSRC ソースファイル は全 NLS ライブラリに追加済み (MAI2928〜MAI2932 は 2026-09-27 追加)。
  • 各ライブラリの MAIMSG には DBT (DBTOMAIL)、SPL (SPLTOMAIL)、SRC (SRCTOMAIL)、 PDF (SPLTOPDF)、MAI (共通エラー) の各メッセージグループが定義されている。
  • ライブラリ名の数字部分は IBM i の NLS 識別番号に対応: 2924=英語, 2928=フランス語, 2929=ドイツ語, 2931=スペイン語, 2932=イタリア語。
  • 各ライブラリの CCSID: MAI2924=37/285 (英語 EBCDIC)、MAI2928=297/500 (フランス語)、 MAI2929=273/500 (ドイツ語)、MAI2931=284/500 (スペイン語)、MAI2932=280/500 (イタリア語)。
