1. 概要

SPLTOMAIL
MAI
V3.06
MAI/SPLTOMAIL (*PGM)
ILE C (SPLTOMAIL.C)
Y.Ide
2000/07/18
IBM i のスプールファイルを SMTP プロトコルで電子メール送信するコマンド。 スプールの内容を「メール本文」「テキスト添付ファイル」「PDF 添付ファイル」の 3 モードで送信できる。 SMTP AUTH (PLAIN) および SSL/TLS (GSKit / DCM) に対応。 CC / BCC / Reply-To の指定、日本語ヘッダーの ISO-2022-JP エンコードにも対応。

6. コマンドパラメーター (SPLTOMAIL)

キーワード型 / 長さ必須デフォルト説明
TO *CHAR(80) × MAX(300) 必須 — 宛先メールアドレス。最大 300 件まで指定可。CASE(*MIXED)
FROM *CHAR(80) 必須 — 発信元 (From) メールアドレス。CASE(*MIXED)
SERVER *CHAR(60) 必須 — SMTP サーバーのホスト名または IP アドレス
FILE *NAME(10) 必須 — 送信するスプールファイル名
SUBJECT *CHAR(128) 省略可 — メール件名 (128 文字以内)。CASE(*MIXED)
JOB QJOB (修飾名) 省略可 * (現行ジョブ) スプールを所有するジョブ名。形式: ジョブ名/ユーザー/番号
SPLNBR *DEC(4) 省略可 *LAST スプール番号。*ONLY(=0) / *LAST(=-1) / 1〜9999
FROMCCSID *CHAR(5) 省略可 5035 スプールファイルの CCSID (日本語 EBCDIC: 5035 / 5026)
SMTPPORT *INT4 省略可 25 (*SMTP) SMTPポート番号。*SMTP=25 / *SMTPS=587 / *SSL=465
SMTPUSR *CHAR(50) 省略可 *NONE SMTP AUTH ユーザー名。*NONE で認証なし
SMTPPWD *CHAR(50) 省略可 — SMTP AUTH パスワード。DSPINPUT(*NO) で入力非表示
SSL *INT4 省略可 *NO SSL/TLS 暗号化使用。*YES(=1) / *NO(=0)。DCM 導入が必要
GSKAPPID *CHAR(50) 省略可 MAI_SMTPS_CLIENT GSKit / DCM アプリケーション ID。SSL=*YES の場合のみ有効
ATTACH *INT4 省略可 *YES 送信モード。*YES(=1): テキスト添付 / *NO(=0): 本文 / *PDF(=2): PDF 添付
ATFILE *NAME(30) 省略可 *FILE 添付ファイル名。PMTCTL: ATTACH(*YES) または ATTACH(*PDF) 時のみ表示
*FILE: スプールファイル名を自動付与 (.txt / .pdf 付加)
KATAKANA *CHAR(5) 省略可 *DBCS 半角カタカナ処理。PMTCTL: ATTACH(*NO) 時のみ表示
*DBCS: 全角変換 / *NONE: そのまま送信
SFTBLANK *INT4 省略可 *YES SO/SI シフト文字のブランク置換。PMTCTL: ATTACH(*NO) 時のみ表示
*YES(=1): 置換 / *NO(=0): 残す

BCC *CHAR(80) × MAX(300) 省略可 — BCC アドレス (最大 300 件)。追加プロンプト

PMTCTL (条件付きプロンプト表示) ルール

P2: KATAKANA / SFTBLANK は ATTACH = 0 (*NO) の場合のみプロンプト表示。
CC / BCC / REPLYTO は PMTCTL(*PMTRQS) — F10 追加プロンプト押下時のみ表示。

7. 処理フロー（SPLTOMAIL.C main()）

  1. パラメーター受け取り — argv[1]〜argv[22] で全 22 パラメーターを受け取る。 CMD PARM 定義順: TO / FROM / SERVER / FILE / SUBJECT / JOB / SPLNBR / FROMCCSID / SMTPPORT / SMTPUSR / SMTPPWD / SSL / GSKAPPID / ATTACH / ATFILE / KATAKANA / SFTBLANK / NOCNV / DEBUG / CC / BCC / REPLYTO
  2. SSL/TLS 初期化 — SSL(*YES) の場合: SMTPRegDCM(GSKAPPID, PORT) を呼び出し DCM アプリケーション登録。 失敗時は DspESCMSG_ID("STM1000") で *ESCAPE 終了。
  3. スプール変換 (ATTACH ≠ *PDF) — SPLTOPF(FILE, JOB, SPLNBR) 呼出。 スプールファイルを QTEMP/PRTPF (物理ファイル) に変換。
  4. 添付ファイル準備 (ATTACH = *YES) — tmpnam() で IFS 一時ファイル名生成 (/TMP...)。 CPYTOSTMF コマンドで QTEMP/PRTPF → IFS テキストファイルに変換 (STMFCODPAG=932)。 添付ファイル名: ATFILE(*FILE) の場合はスプールファイル名 + .txt。
  5. PDF 変換 (ATTACH = *PDF) — SPLTOPDF(FILE, JOB, SPLNBR, DIR, PDFFILE, FONT, FROMCCSID, DUPOPT) 呼出。 IFS 一時 PDF パスを PPDFPATH に設定 (wStmf + ".pdf")。 添付ファイル名: スプールファイル名 + .pdf。
  6. 本文直接送信準備 (ATTACH = *NO) — _Ropen("QTEMP/PRTPF","rr") で物理ファイルをオープン。 _Ropnfbk() でレコード件数 / レコード長を取得。レコード 0 件は DspESCMSG_ID("STM1020") で終了。
  7. 変換設定 — SMTPSetDebug() / SMTPSetSftSp() / SMTPSetConvert(fromCCSID, 5054, kana) で文字変換モードを設定 (kana=1: *DBCS 全角変換)。
  8. SMTP ヘッダー生成 — SMTPOpen(SERVER, PORT) → From → To (全件ループ) → CC (全件ループ) → BCC (全件ループ) → SMTPDate() → SMTPSubj(SUBJECT) → SMTPOther("Reply-To:", REPLYTO) → SMTPMsgID()。 NOCNV=1 の場合は SMTPFromNoConvert() / SMTPRcptNoConvert() を使用。 無効アドレスは DspDIAGMSG_ID("STM1030") で警告継続。
  9. MIME 設定 — 添付時: SMTPMIME("multipart/mixed") / 本文時: SMTPMIME("text/plain")。 添付時は SMTPMpartText() でマルチパート本文パート開始。
  10. ボディ / 添付送信
    ATTACH=*NO: _Rreadn() ループで全レコードを SMTPWrite()。ソースファイル形式 (isSRCF='Y') は buf[12] からの送信。
    ATTACH=*YES/*PDF: スプール情報 (SPLF NAME / JOB / SPOOL NUMBER) をマルチパート本文として書込後、SMTPMpartAttach() で添付。 *PDF は application/pdf、*YES は application/octet-stream。SMTPMpartClose() で終了。
  11. SMTP 送信 — SMTPUSR=*NONE: SMTPSend() / それ以外: SMTPSendAuth(USR, PWD, SSL, GSKAPPID)。
  12. 後処理 — SMTPClose() → ATTACH=*NO 時のみ _Rclose(fp) → ATTACH=*YES/*PDF 時は DEL OBJLNK() で IFS 一時ファイルを削除。 MAI9899 例外が捕捉されていた場合は DspINFOMSG_ID("MAI9899") 送信。
例外ハンドラー: #pragma exception_handler(_handler, 0, 0, _C2_MH_ESCAPE, _CTLA_HANDLE, "MAI9899")
MAI9899 *ESCAPE メッセージを受信した場合、mai9899_caught フラグを立てて exit(0)。 正常終了後に DspINFOMSG_ID("MAI9899") として再送信される。

8. 補助プログラム詳細

8.1 SPLTOPF (CLP) — スプールファイルを QTEMP/PRTPF に変換

  1. QUSRSPLA (SPLA0100) で スプールファイル属性取得 — ページ幅 (offset 429) / SO/SI スペース指示 (offset 461) を抽出
  2. CRTPF QTEMP/PRTPF RCDLEN(幅×1.5) — 出力物理ファイル作成 (既存時は DLTF 後再作成)
  3. CRTPF QTEMP/SPLPF RCDLEN(幅+5) — CPYSPLF 用中間物理ファイル作成
  4. CPYSPLF で指定ジョブ/スプール番号 (*LAST / *ONLY / 番号) を QTEMP/SPLPF にコピー (CTLCHAR(*PRTCTL))
  5. OVRDBF 設定後 SPLTOPFR(RECLEN, SOSISP) 呼出 → DLTOVR / DLTF QTEMP/SPLPF

8.2 SPLTOPFR (OPM RPG) — CTLCHAR 解析と物理ファイル書き出し

  1. SPLPF (入力) / PRTPF (出力) をファイル定義で使用。レコード長は外部で指定 (9999 上限)
  2. 印刷制御文字 (SKP / SPC) を解析: SKP: 指定行番号 < 現行行 → 改頁出力 (SEP レコード) / ≥ 現行行 → 空行 (CRLF) で行送り
    SPC: 1/2/3 のスペース行数分だけ空レコード (CRLF) を出力
  3. SOSISP ≠ *NO の場合: SO (X'0E') / SI (X'0F') の前後にスペースを挿入して DBCS を展開
  4. 展開後データを PRTPF (E#OUT) に書き出し。LR セットで終了

8.3 SPLTOPDF (ILE BNDCL) — スプールを IFS PDF に変換

パラメーター: &FILE(10) / &QJOB(26) / &SPLNBR DEC(6,0) / &DIR(512) / &PDFFILE(128) / &FONT(512) / &FROMCCSID(5) / &DUPOPT(8)

  1. ADDLIBLE QFNTCPL — 日本語フォントライブラリーをライブラリーリストに追加
  2. QUSRSPLA でスプール属性を取得。プリンターデバイス種別 (offset 319) を &PRTDEVTYP に抽出
  3. CCSID 解決: FROMCCSID(*JOB) → RTVJOBA CCSID / RTVSYSVAL QCCSID で解決
  4. フォントパス解決: FONT(*DFT) → /MAI/fonts/SourceHanSans-VF.ttf
  5. 出力パス構築: PDFFILE(*SPLF) → ファイル名_番号.pdf / DIR(*HOME) → /home/ユーザー名
  6. 重複処理 (DUPOPT):
    *REPLACE: STMFOPT(*REPLACE) で上書き
    *NONE: DSPLNK で存在確認 → 存在時 CPF9898 *ESCAPE
    *RENAME: stem_1.pdf, stem_2.pdf... と空き名を検索
  7. *SCS スプール: SPLTOPF → CPYTOSTMF (PRTPF → IFS .tmp) → TXTTOPDF(.tmp, .pdf, CCSID, FONT) → .tmp 削除
    それ以外: CPYSPLF WSCST(*PDF) で直接 IFS PDF に変換
  8. 完了メッセージ PDF1015 (*COMP) を MAIMSG メッセージファイルから送信 (MSGDTA = *CCHAR *VARY2 パス)

9. ビルド手順（MAIV300S/QMAKESRC/MSPLTOMAIL.CLP）

  1. CRTCLPGM PGM(MAI/SPLTOPF) SRCFILE(*CURLIB/QCLSRC) → MAI/SPLTOPF *PGM
  2. CRTRPGPGM PGM(MAI/SPLTOPFR) SRCFILE(*CURLIB/QRPGSRC) → MAI/SPLTOPFR *PGM
  3. CRTCMD CMD(MAI/SPLTOPF) PGM(MAI/SPLTOPF) SRCFILE(*CURLIB/QCMDSRC) → MAI/SPLTOPF *CMD
  4. CRTBNDCL PGM(MAI/SPLTOPDF) SRCFILE(*CURLIB/QCLSRC) SRCMBR(SPLTOPDF) DBGVIEW(*ALL) AUT(*EXCLUDE) → MAI/SPLTOPDF *PGM
  5. CRTCMOD MODULE(*CURLIB/SPLTOMAIL) SRCFILE(*CURLIB/QCSRC) DBGVIEW(*ALL) SYSIFCOPT(*IFSIO) → MAIV300S/SPLTOMAIL *MODULE
  6. CRTPGM PGM(MAI/SPLTOMAIL) MODULE(*CURLIB/SPLTOMAIL) BNDSRVPGM(MAI/SMTPSRVS) ACTGRP(*NEW) AUT(*EXCLUDE) → MAI/SPLTOMAIL *PGM
  7. CRTPNLGRP PNLGRP(MAI/SPLTOMAIL) SRCFILE(MAIV300S/QHLPSRC) SRCMBR(SPLTOMAIL) → MAI/SPLTOMAIL *PNLGRP
  8. CRTCMD CMD(MAI/SPLTOMAIL) PGM(MAI/SPLTOMAIL) SRCFILE(MAIV300S/QCMDSRC) PMTFILE(MAI/MAIMSG *DYNAMIC) HLPPNLGRP(MAI/SPLTOMAIL) HLPID(SPLTOMAIL) → MAI/SPLTOMAIL *CMD
  9. オーナー変更: CHGOBJOWN NEWOWN(QPGMR) CUROWNAUT(*REVOKE) — 対象: MAI/SPLTOMAIL *PGM / MAI/SMTPSRVS *SRVPGM / MAI/SPLTOMAIL *CMD / MAI/SPLTOMAIL *PNLGRP
注意: MAI/SMTPSRVS *SRVPGM の再ビルドが必要な場合は MAKE ファイル内のコメントアウト部分 (CRTCMOD SMTPSRVS / CRTSRVPGM SMTPSRVS) を有効化してください。 新しい公開関数追加時は MAIV300S/QSRVSRC/SMTPSRVS.BND のエクスポート定義も更新が必要です。

10. 使用例

例 1: 基本送信（メール本文として送信）

SPLTOMAIL  FILE(QSYSPRT)
           TO(user@example.com)
           FROM(sender@example.com)
           SERVER(smtp.example.com)
           ATTACH(*NO)

現行ジョブの最後の QSYSPRT スプールファイルをメール本文として送信します。

例 2: テキスト添付送信（デフォルト動作）

SPLTOMAIL  FILE(QSYSPRT)
           TO(user@example.com)
           FROM(sender@example.com)
           SERVER(smtp.example.com)
           SUBJECT('月次レポート')
           ATTACH(*YES)
           ATFILE(monthly_report)

スプールファイルを monthly_report.txt として添付してメール送信します。

例 3: PDF 添付 + SSL/TLS + SMTP AUTH（Gmail など）

SPLTOMAIL  FILE(QSYSPRT)
           TO(user@example.com)
           FROM(account@gmail.com)
           SERVER(smtp.gmail.com)
           SUBJECT('Monthly Report')
           SMTPPORT(*SMTPS)
           SMTPUSR(account@gmail.com)
           SMTPPWD(app_password)
           SSL(*YES)
           ATTACH(*PDF)
           FROMCCSID(5035)

スプールファイルを PDF 変換し、ポート 587 (STARTTLS) 経由で SMTP AUTH 送信します。DCM に MAI_SMTPS_CLIENT の登録が必要です。

例 4: 別ジョブのスプール・複数宛先 + CC

SPLTOMAIL  FILE(QPJOBLOG)
           JOB(123456/QUSER/BATCHJOB)
           SPLNBR(3)
           TO(admin@example.com manager@example.com)
           FROM(ibmi@example.com)
           SERVER(smtp.example.com)
           SUBJECT('BATCHJOB ジョブログ')
           ATTACH(*YES)

指定ジョブのスプール番号 3 を 2 宛先に添付送信します。

例 5: デバッグモード

SPLTOMAIL  FILE(QSYSPRT)
           TO(debug@example.com)
           FROM(sender@example.com)
           SERVER(smtp.example.com)
           DEBUG(*YES)

SMTP 送受信の全コマンドがジョブログに記録されます。

11. メッセージ / エラー

SPLTOMAIL では MAIMSG メッセージファイルを使用してメッセージを送信します。

メッセージ ID種別説明対処
STM1000 *ESCAPE DCM アプリケーション登録失敗 (SMTPRegDCM エラー) DCM に GSKAPPID で指定したアプリケーション ID が登録されているか確認
STM1010 *ESCAPE 入力ファイル (QTEMP/PRTPF) がオープンできない SPLTOPF が正常終了しているか確認。ファイル変換に失敗している可能性あり
STM1020 *ESCAPE レコード件数が 0 件 — スプールファイルに内容がない スプールファイルの出力内容を確認する
STM1030 *DIAG 送信できないアドレスが含まれている (SMTPValidAddr で検証失敗) TO / CC / BCC の指定アドレス書式を確認。処理は継続し有効アドレスのみ送信
MAI9899 *INFO 例外ハンドラーで捕捉した MAI9899 メッセージを正常終了後に再通知 ジョブログで前後のメッセージを確認する
PDF1015 *COMP SPLTOPDF 正常完了 — 生成された PDF の IFS パスを通知 ATTACH(*PDF) 使用時のみ。MSGDTA に *CCHAR *VARY2 形式でパスが含まれる
CPF9899 *ESCAPE SPLTOPF / SPLTOPDF 内の汎用エラー ジョブログの直前の *DIAG メッセージで詳細を確認
CPF9801 / CPF9810 *ESCAPE オブジェクト / ライブラリーが見つからない MAI ライブラリーがライブラリーリストに追加されているか確認
