1. 概要

SMTPSRVS は IBM i 上で動作する SMTP メール送信サービスプログラム の ILE C ソースです。 SMTP プロトコルを使ってメールを送信するために必要なすべての低レベル処理（ソケット通信・文字変換・MIME エンコード・SSL/TLS・SMTP 認証）を提供します。

このモジュール単体では動作せず、呼び出し元プログラム（SRCTOMAIL、SPLTOMAIL、DBTOMAIL 等）からサービスプログラムとしてバインドされて利用されます。

主な機能

  • SMTP 接続管理（平文 Port 25 / SSL Port 465 / STARTTLS Port 587）
  • SMTP 認証（AUTH PLAIN / AUTH LOGIN）
  • メールヘッダー生成（From / To / Cc / Bcc / Subject / Date / Message-Id 等）
  • 文字コード変換（EBCDIC → JIS / Shift_JIS / EUC-JP / ASCII）
  • 半角カナ → 全角変換（CCSID 5035 / 5026 両対応）
  • MIME エンコーディング（Base64・RFC1522 件名エンコード・マルチパート添付）
  • DCM アプリケーション ID の登録・解除（GSKit TLS 用）
  • AES 暗号化されたライセンスキーファイルの検証

5. 公開関数 (API) 一覧

以下はサービスプログラムとして呼び出し元に公開される関数です。

関数名 シグネチャ 役割
SMTPRegDCM SSL int SMTPRegDCM(char *GSKAPPID, int SMTPPort) DCM へアプリケーション ID を登録し、SSL（Port 465）または STARTTLS（Port 587）モードを設定する。DCM LPP のインストール確認も行う。
SMTPSetSftSp int SMTPSetSftSp(int SetSftSP) 制御文字をスペースに置換するソフトスペースモードを ON（1）/ OFF（0）で切り替える。
SMTPSetConvert int SMTPSetConvert(int fromccsid, int toccsid, int katakana) EBCDIC → JIS / Shift_JIS / EUC-JP 等の汎用変換コンバーターを iconv_open で初期化する。
SMTPOpen int SMTPOpen(char *SMTPServer, int SMTPPort) SMTP サーバーアドレス解決、一時ファイル作成、変換コンバーター（acd/ecd/jcd）初期化。ライセンスキーチェックを実行。失敗時は -1 を返す。
SMTPClose int SMTPClose(void) コンバーター・一時ファイル・ソケットのクリーンアップ。
SMTPFromNoConvert int SMTPFromNoConvert(char *From) EBCDIC 変換なしで From: ヘッダーを一時ファイルに書き込む。
SMTPFrom int SMTPFrom(char *From) DBCS → JIS 変換（RFC1522 エンコード）しつつ From: ヘッダーを書き込む。
SMTPRcptNoConvert int SMTPRcptNoConvert(char *RcptType, char *Rcpt) 変換なしで宛先（To / Cc / Bcc）ヘッダーを書き込む。BCC は一時ファイルに出力しない。
SMTPRcpt int SMTPRcpt(char *RcptType, char *Rcpt) DBCS → JIS 変換しつつ宛先ヘッダーを書き込む。
SMTPSubj int SMTPSubj(char *Subj) 件名を半角→全角変換後、DBCS 部分を RFC1522 エンコード（=?ISO-2022-JP?B?...?=）して Subject: ヘッダーに書き込む。32バイト超えのDBCSは折り返し処理あり。
SMTPDate int SMTPDate(void) RFC 形式（%a, %d %b %Y %H:%M:%S +0900）の Date: ヘッダーを書き込む。
SMTPMsgID int SMTPMsgID(void) QDATETIME（マイクロ秒）＋ジョブ番号＋From アドレスで Message-Id: を生成・書き込む。
SMTPMIME int SMTPMIME(char *Content) MIME-Version: 1.0 と Content-Type ヘッダーを書き込む。charset は ToCCSID に基づき自動選択。
SMTPMpartText int SMTPMpartText(void) マルチパートのテキスト部境界（--boundary）と Content-Type: text/plain を書き込む。
SMTPMpartAttach int SMTPMpartAttach(char *IFSname, char *ContentType, char *Name, char *Desc) IFS ファイルを 57 バイト単位で読み込み、Base64 エンコードして添付ファイルとして書き込む。
SMTPMpartClose int SMTPMpartClose(void) マルチパートの終端境界（--boundary--）を書き込む。
SMTPOther int SMTPOther(char *Type, char *TypeStr) 任意のカスタムヘッダー行（Type TypeStr\n）を書き込む。
SMTPEtcWrite int SMTPEtcWrite(char *etcStr) 任意の文字列をそのまま一時ファイルに書き込む。
SMTPCrWrite int SMTPCrWrite(void) 改行（\n）を一時ファイルに書き込む。
SMTPCommaWrite int SMTPCommaWrite(void) カンマ（,）を一時ファイルに書き込む。
SMTPValidAddr int SMTPValidAddr(char *MailAddr) メールアドレスの簡易検証。@ が含まれない場合は -1 を返す。
SMTPBody int SMTPBody(void) X-Mailer: MAI/400 Version 3.00 ヘッダーと空行（ヘッダー/ボディ区切り）を書き込む。
SMTPWrite int SMTPWrite(char *Text) 本文1行を書き込む。KanaSW=1 の場合は半角→全角変換を実施。
SMTPSend int SMTPSend(void) 認証なし SMTP 送信（HELO/MAIL FROM/RCPT TO/DATA）。Base64 部分は変換せずそのまま送信。
SMTPSendAuth SSL int SMTPSendAuth(char *AuthUsr, char *AuthPwd, int SMTPS, char *GSKAPPID) 認証あり SMTP 送信。EHLO → 認証方式選択 → SSL ハンドシェイク（STARTTLS対応）→ RSET/MAIL FROM/RCPT TO/DATA/QUIT を実行。
SMTPSetDebug void SMTPSetDebug(int debug) デバッグモード ON/OFF。1 を指定すると SMTP コマンド送受信内容を *DIAG/*STATUS メッセージで出力する。

メッセージファイル

  • QCPFMSG（*LIBL）― システムメッセージ。CPF9898 ID を使って任意文字列を送信。
  • MAIMSG（*LIBL）― MAI/400 専用メッセージファイル。MAI0010〜MAI0240 等のメッセージ ID を使用。
