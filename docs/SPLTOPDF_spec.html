1. 機能概要

SPLTOPDF は、IBM i のスプールファイルを IFS (統合ファイルシステム) 上の PDF ファイルに変換して保存する ILE CL プログラムです。

スプールファイルのプリンター装置タイプ (PRTDEVTYP) に応じて、以下の 2 つの変換ルートを使い分けます。

  • *SCS ルート: 独自 PDF エンジンを使用。SPLTOPF で物理ファイルに展開後、CPYTOSTMF でテキスト変換し、TXTTOPDF (ILE C) で PDF 生成する。TTF フォント指定・CCSID 指定が可能。
  • その他ルート: システム標準の CPYSPLF WSCST(*PDF) を使用して PDF に変換する。*AFPDS / *IPDS など *SCS 以外のスプール向け。

出力先フォルダー・PDF ファイル名・TTF フォント・入力 CCSID・重複ファイル処理をパラメーターで制御できます。 PDF 生成完了後は MAIMSG/PDF1015 (*COMP) メッセージで出力パスを呼び出し元に通知します。 SPLTOMAIL コマンドから ATTACH(*PDF) モード時に内部的に呼び出されるほか、 単独コマンド (MAI/SPLTOPDF) としても使用できます。

2. 呼び出し方法 — コマンド SPLTOPDF

コマンド定義 MAIV300S/QCMDSRC(SPLTOPDF.CMD) で定義されています。 プログラムは MAI/SPLTOPDF として呼び出されます。

8. エラー処理方針

  • プログラム先頭の MONMSG CPF0000 EXEC(GOTO CMDLBL(ERRLABEL)) で全 CPF エラーをキャッチする大域モニターを設定する。
  • ERRLABEL では SNDPGMMSG MSGID(CPF9899) MSGF(QCPFMSG) MSGTYPE(*ESCAPE) で *ESCAPE メッセージを送出し、呼び出し元 (SPLTOMAIL 等) にエラーを伝播する。
  • DUPOPT=*NONE 時に出力先ファイルが既存であれば CPF9898 *ESCAPE を送出して即座に中断する。
  • ADDLIBLE の CPF2103（ライブラリー既追加）は個別に MONMSG で無視する。
  • RMVLNK の CPFA09C / CPCA089 / CPF0000（一時ファイル削除失敗）は個別に MONMSG で無視する。
  • DSPLNK の CPFA0A9（ファイル未発見）は DUPOPT 処理内で NODUP / FREENAME ラベルへのジャンプに利用する。

13. 特記事項

  • ルート判定は QUSRSPLA SPLA0100 フォーマットの offset 319 (PRTDEVTYP) の先頭 4 文字が '*SCS' かどうかで行う。
  • *SCS ルートでは TTF フォントを使用した独自 PDF エンジン (TXTTOPDF) を使用するため、日本語フォント (SourceHanSans-VF.ttf) の配置が必要。デフォルトパスは /MAI/fonts/SourceHanSans-VF.ttf。
  • TXTTOPDF へ渡す引数はすべてヌル終端 C 文字列であるため、CL 変数に X'00' を連結した &STMFN・&TMPSTMFN・&FONTTRIMN・&TXTCCSID を使用する。
  • SPLTOPF のパラメーター型は *DEC LEN(4,0) であるため、&SPLNBR (LEN 6,0) を &SPLNBR4 (LEN 4,0) に変換してから呼び出す。
  • CPYTOSTMF では DBFCCSID(*FILE) / STMFCODPAG(*STMF) を指定し、変換なしで IFS に書き出す。CCSID 変換は TXTTOPDF 側で行う。
  • *SPLF ファイル名は FILE_NNN.pdf 形式（FILE = スプールファイル名、NNN = 実スプール番号）。スプール番号は QUSRSPLA が返す実番号を使用する（入力 SPLNBR が *LAST の場合でも実番号が格納される）。
  • DUPOPT=*RENAME では %LOWER と %SCAN で .pdf 拡張子を検出し、ステム部分と連番を組み合わせて空きファイル名を探す。&DOTPOS に ILE CL 固有の *UINT 型を使用しているため、CRTBNDCL (ILE CL) でのコンパイルが必須。
  • PDF 生成完了後は MAIMSG/PDF1015 (*COMP) メッセージで出力 IFS パスを呼び出し元に送信する。メッセージデータは *CCHAR *VARY 2 形式（先頭 2 バイトが BIN でパス長、続いてパス文字列）。
  • RMVLNK の MONMSG は CPFA09C CPCA089 CPF0000 の 3 メッセージを無視する。
  • QFNTCPL ライブラリーは ADDLIBLE で追加するが、すでにライブラリーリストにある場合の CPF2103 は無視する。
  • プログラムは AUT(*EXCLUDE) で作成される。
