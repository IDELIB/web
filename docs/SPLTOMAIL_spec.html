1. 機能概要

SPLTOMAIL は、IBM i (AS/400) のスプールファイルを読み取り、 その内容を SMTP プロトコルでメール送信する ILE C プログラムです。 SMTP サービスプログラム (SMTPSRVS) を内部で呼び出して実際の通信を行います。

主な機能は以下のとおりです。

  • スプールファイルをメール本文として送信 (ATTACH(*NO))
  • スプールファイルをテキストファイル (.txt) として添付送信 (ATTACH(*YES))
  • スプールファイルを PDF に変換して添付送信 (ATTACH(*PDF)、SPLTOPDF 連携)
  • MIME マルチパートによる添付ファイル送信 (application/pdf / application/octet-stream)
  • To / Cc / Bcc / Reply-To ヘッダー対応（各最大 300 件）
  • EBCDIC → JIS 文字コード変換 (iconv / CCSID 5054 固定)
  • カタカナ SBCS ↔ DBCS 変換オプション
  • SMTP 認証 (PLAIN / LOGIN) 対応
  • STARTTLS / SSL (GSKit DCM) による暗号化通信対応
  • スプールを物理ファイルに展開する補助プログラム群 (SPLTOPF / SPLTOPFR / SPLTOPDF) との連携

6. 内部関数

main(int argc, char *argv[])

プログラムのエントリーポイント。パラメーター受け取りからスプール展開・添付/本文送信・SMTP 送信完了までの一連の処理を制御する。

void DspESCMSG(char *msg)

QCPFMSG CPF9898 を *DIAG として送信し _Rclose(fp) でファイルをクローズしてから exit(0) で終了する。
※ SRCTOMAIL とは異なり、メッセージ ID ではなくテキスト直接指定方式。

void DspDIAGMSG(char *msg)

QCPFMSG CPF9898 を *DIAG として送信し exit(0) で終了する。ファイルのクローズは行わない。（ファイル未オープン時のエラー用）

10. エラー処理方針

  • 致命的エラー（DCM 登録失敗・ファイルオープン失敗・レコード 0 件）は DspESCMSG_ID() により MAIMSG メッセージファイルのメッセージ ID を指定して *ESCAPE で終了する。
  • DspESCMSG_ID() は _Rclose(fp) を呼び出してからメッセージ送信する。DspDIAGMSG_ID() はファイルクローズなしで終了する（ファイル未オープン時向け）。
  • アドレス検証失敗は DspDIAGMSG_ID("STM1030") で *DIAG 警告のみ送信し、有効なアドレスのみで処理を継続する。
  • V3.06 よりメッセージは MAIMSG メッセージファイルからメッセージ ID で送信する方式に統一（V3.05 以前の CPF9898 テキスト直接方式から変更）。
  • MAI9899 *ESCAPE メッセージは例外ハンドラーで捕捉し、正常終了後に *INFO として再通知する。
  • 添付用 IFS 一時ファイルは送信完了後に DEL OBJLNK(wStmf) で必ず削除する。

13. 特記事項

  • 出力 CCSID (tccsid) は常に 5054 (JIS) 固定。SRCTOMAIL のように TOCCSID パラメーターで変更できない。
  • ATTACH(*YES) 時は CPYTOSTMF STMFCODPAG(932) で Shift-JIS に変換して IFS 一時ファイルに保存し、SMTPMpartAttach で添付する。
  • ATTACH(*PDF) 時は SPLTOPDF ILE BNDCL を OS リンケージで呼び出す。パラメーターは FILE / QJOB / SPLNBR / DIR / PDFFILE / FONT / FROMCCSID / DUPOPT。PDF ファイルパスは wStmf + ".pdf"。NUL バイト (0x00) は EBCDIC スペース (0x40) に置換してから渡す（v3.04 修正）。
  • IFS 一時ファイルは tmpnam() で生成後、CCSID 5026 への対応として wStmf[1..3] を強制的に 'T','M','P' に書き換える。
  • 添付送信 (PATTACH == 1 / 2) 時は _Rclose(fp) を呼び出さない（v3.05 修正）。本文送信 (PATTACH == 0) 時のみ _Rclose(fp) を呼び出す。
  • スプールファイル情報（SPLF NAME / JOB / SPOOL NUMBER）を本文の先頭 3 行として書き込む（添付モード時）。
  • JOB パラメーターに *（現行ジョブ）を指定した場合、QUSRJOBI API で実際のジョブ名/ユーザー/番号を取得する。
  • バッファーサイズは最大 1,024 バイト（buf[1024]）。SRCTOMAIL の 32,767 バイトより小さい（スプールファイルの 1 行は最大 198 文字程度を想定）。
  • ソースファイル形式 (isSRCF='Y') のレコードは buf[12] 以降を送信する（シーケンス番号・日付フィールドをスキップ）。
  • V3.06 よりエラーメッセージは MAIMSG メッセージファイルから ID 指定で送信する方式に統一。コマンドのプロンプトファイル (PMTFILE) にも MAI/MAIMSG *DYNAMIC を使用。
  • プログラムのアクティベーショングループは ACTGRP(*NEW)（MSPLTOMAIL.CLP より）。
  • AUT(*EXCLUDE) で作成される（MSPLTOMAIL.CLP の CRTPGM / CRTBNDCL に明示）。オーナーは CHGOBJOWN NEWOWN(QPGMR) CUROWNAUT(*REVOKE) で QPGMR に変更する。
