1. ヘルプ表示の仕組み — 全体ヘルプ vs コンテキストヘルプ

UIM の Help 表示には2種類あり、動作が全く異なる。

種別 起動方法 表示されるヘルプ 連結対象
全体ヘルプ（Extended Help） コマンドライン（===>）上で F1 PANEL の HELP= で指定したヘルプID パネル上の全要素ヘルプが自動連結される
コンテキストヘルプ 特定フィールド／列にカーソルを置いて F1 そのフィールド・列・キーの HELP= で指定したヘルプID のみ 連結なし（そのIDのみ単独表示）
ポイント コマンドライン上で F1 を押したときだけ「全体ヘルプ」になる。 OPT 列にカーソルがある状態で F1 を押すと、LISTCOL HELP='WRKMSPLF/HOPT' の コンテキストヘルプが表示される。

2. 全体ヘルプの自動連結順序

コマンドライン F1 で表示される全体ヘルプは、パネル定義の記述順に 各要素のヘルプが自動的に連結される。明示的な :IMHELP. を書かなくても 以下の順序でヘルプ本文が結合される。

PANEL HELP='…/MAIN'
→
LISTCOL HELP='…/HOPT'
（OPT列）
→
LISTCOL HELP='…/HFIL'
（FIL列）
→
… 各列 …
→
KEYL HELP='…/KEYL'
連結元タグ 連結されるヘルプID 備考
:PANEL HELP='…/MAIN' WRKMSPLF/MAIN パネルの本文ヘルプ（先頭）
:LISTCOL HELP='…/HOPT' WRKMSPLF/HOPT OPT列ヘルプが自動連結
:LISTCOL HELP='…/HFIL' 〜 HCPY 各列ヘルプ LISTCOL 記述順に連結
:KEYL HELP='…/KEYL' WRKMSPLF/KEYL 機能キー一覧ヘルプ（末尾）
注意 :LISTACT HELP= で指定した個別オプションヘルプ（OPT2〜OPT14）は、 全体ヘルプには自動連結されない。コンテキストヘルプ専用。

3. 見出しタグの正解 — :XH3. の使い方

全体ヘルプで「オプション」「列の説明」「機能キー」などを 高輝度（ハイライト）見出しとして表示するには :XH3. タグを使う。

正しいタグ

:HELP NAME='WRKMSPLF/HOPT'.オプション (OPT) - ヘルプ
:XH3.オプション
:P.実行したい機能のオプション番号を入力してください。
...

使えないタグ

タグ 結果 理由
:SL. NG コンパイルエラー CPD5A8C セクション見出しではなく単純リストタグ
:XH1. / :XH2. NG 使用不可（パネルグループの制約） ヘルプの入れ子レベルが不正
:XH3. OK 高輝度見出しとして表示 HELP モジュール内で使える第3レベル見出し
:XH4. 以降 可 より低レベルの見出し ネストしたセクションに使用可
覚え方 ヘルプテキスト内のセクション見出し = :XH3. 一択。 WRKSPLF など IBM 標準コマンドのパネルグループも同タグを使用している。

4. 重複表示の罠 — :IMHELP と LISTCOL の二重連結

最もハマりやすいのが :IMHELP. と LISTCOL の自動連結による 同一セクションの2回表示問題。

問題が発生するパターン

:HELP NAME='WRKMSPLF/MAIN'.
:P.パネルの説明文 ...
:IMHELP NAME='WRKMSPLF/HOPT'.   <-- (A) 明示的に HOPT を埋め込む
:XH3.列の説明
...
:EHELP.

:LISTCOL VAR=OPT
         HELP='WRKMSPLF/HOPT'.  <-- (B) LISTCOL が HOPT を自動連結
MAIN ヘルプ本文
→
HOPT（A: :IMHELP で挿入）
→
列の説明 セクション
→
HOPT（B: LISTCOL が自動連結）
→
KEYL
結果 全体ヘルプに「オプション」セクションが2回表示される。

正しい設計（:IMHELP を削除するだけで解決）

:HELP NAME='WRKMSPLF/MAIN'.
:P.パネルの説明文 ...
.*  :IMHELP NAME='WRKMSPLF/HOPT'. <-- 削除！ LISTCOL が自動連結するので不要
:XH3.列の説明
...
:EHELP.

:LISTCOL VAR=OPT
         HELP='WRKMSPLF/HOPT'.   <-- これだけで HOPT が1回だけ連結される
MAIN ヘルプ本文
→
列の説明 セクション
→
HOPT（LISTCOL 自動連結 × 1回）
→
KEYL
原則 :LISTCOL HELP= / :KEYL HELP= が指定されていれば、 そのIDは全体ヘルプへ自動連結される。 :IMHELP. で同じIDを MAIN に書くのは二重連結になる。

5. 列ヘルプ・キーヘルプの正しい設計パターン

列ヘルプ（HFIL〜HCPY）と個別キーヘルプ（KF1〜KPGUP）は タイトルのみ定義し、本文は集約先に1か所だけ書く。

列ヘルプの設計

ヘルプID 内容 本文
WRKMSPLF/HFIL タイトルのみ「ファイル (FILE) - ヘルプ」 MAIN の :XH3.列の説明 :PARML. に集約
WRKMSPLF/HUSR タイトルのみ「ユーザー (USER) - ヘルプ」 同上
… 以下同様 … 
.*-- 列ヘルプはタイトルだけ。本文は MAIN に集約 --
:HELP NAME='WRKMSPLF/HFIL'.ファイル (FILE) - ヘルプ
:EHELP.
:HELP NAME='WRKMSPLF/HUSR'.ユーザー (USER) - ヘルプ
:EHELP.

列ヘルプにタイトルがあることで、コンテキストヘルプ（列にカーソルを置いて F1）で 「ファイル (FILE) - ヘルプ」というタイトルバーが表示される。本文は 全体ヘルプの MAIN 内 :PARML. から読む設計。

キーヘルプの設計

.*-- キーヘルプはタイトルだけ。本文は KEYL の :PARML. に集約 --
:HELP NAME='WRKMSPLF/KF3'.F3=終了 - ヘルプ
:EHELP.
:HELP NAME='WRKMSPLF/KF4'.F4=プロンプト - ヘルプ
:EHELP.

KEYL に全キー説明を集約

:HELP NAME='WRKMSPLF/KEYL'.機能キー
:XH3.機能キー
:PARML.
:PT.F3=終了
:PD.プログラムを終了し、呼び出し元の画面に戻ります。
:PT.F4=プロンプト
:PD.OPT 欄に入力したオプションのコマンドのプロンプト画面を表示します。
...
:EPARML.
:EHELP.
なぜタイトルだけにするか 各列・各キーに本文を書くと、全体ヘルプで本文が重複する。 タイトルのみにすることでコンテキストヘルプのタイトルバーだけが変わり、 全体ヘルプでは集約先の本文が1回だけ表示される。

6. OPT 列 F1（コンテキストヘルプ）の設計

OPT 列にカーソルを置いて F1 を押したときは LISTCOL HELP='WRKMSPLF/HOPT' のコンテキストヘルプが単独表示される。HOPT 自体に :XH3.オプション と本文を持たせておくことで、コンテキスト・全体ヘルプの両方で正しく機能する。 

:HELP NAME='WRKMSPLF/HOPT'.オプション (OPT) - ヘルプ
:XH3.オプション
:P.実行したい機能のオプション番号を入力してください。
...
:PARML.
:PT.2= 変更
:PD.スプール・ファイルの属性を変更します (CHGSPLFA)。
...
:EPARML.
:EHELP.

個別オプションヘルプ（OPT2〜OPT14）

:LISTACT HELP='WRKMSPLF/OPT2' で参照される個別オプションヘルプは タイトルのみ定義する。本文は HOPT の :PARML. に集約。 

:HELP NAME='WRKMSPLF/OPT2'.2= 変更
:EHELP.
:HELP NAME='WRKMSPLF/OPT3'.3= 保留
:EHELP.
動作確認の注意 コマンドライン（===>）にカーソルを置いてから F1 を押さないと 全体ヘルプにならない。OPT 列にカーソルがある状態で F1 を押すと コンテキストヘルプ（HOPT）が表示される。

7. 推奨ソース構造テンプレート

以下の順序でヘルプIDを定義するのが推奨パターン。

:PNLGRP.
.*-- クラス・変数・VARRCD・LISTDEF 定義 --
.*-- KEYL 定義 --
.*-- PANEL 定義（LISTACT, LISTCOL, LISTVIEW 含む）--
:EPANEL.

.*===================================================
.*  ヘルプ本文
.*===================================================
.*
.* (1) パネル全体ヘルプ + 列の説明セクション
:HELP NAME='XXX/MAIN'.パネルタイトル (コマンド名) - ヘルプ
:P.説明文 ...
.*  ※ :IMHELP NAME='XXX/HOPT'. は書かない！ LISTCOL が自動連結
:XH3.列の説明
:PARML.
:PT.列1見出し
:PD.列1の説明 ...
...
:EPARML.
:EHELP.

.* (2) キー一覧ヘルプ（機能キーセクション見出し付き）
:HELP NAME='XXX/KEYL'.機能キー
:XH3.機能キー
:PARML.
:PT.F3=終了
:PD.プログラムを終了します。
...
:EPARML.
:EHELP.

.* (3) OPT 列ヘルプ（オプションセクション見出し付き・本文含む）
:HELP NAME='XXX/HOPT'.オプション (OPT) - ヘルプ
:XH3.オプション
:P.オプション番号を入力してください。
:PARML.
:PT.2= 変更
:PD.説明 ...
...
:EPARML.
:EHELP.

.* (4) 各列ヘルプ（タイトルのみ・本文は MAIN に集約）
:HELP NAME='XXX/HFIL'.ファイル (FILE) - ヘルプ
:EHELP.
:HELP NAME='XXX/HUSR'.ユーザー (USER) - ヘルプ
:EHELP.
.* ...（他の列）...

.* (5) コマンドプロンプトヘルプ（HLPID=XXXC）
:HELP NAME='XXXC'.コマンド名
:P.コマンドの概要説明 ...
:EHELP.
:HELP NAME='XXXC/PARM1'.パラメーター名 - ヘルプ
:P.パラメーターの説明 ...
:EHELP.

.* (6) 個別オプションヘルプ（タイトルのみ・本文は HOPT に集約）
:HELP NAME='XXX/OPT2'.2= 変更
:EHELP.
:HELP NAME='XXX/OPT3'.3= 保留
:EHELP.
.* ...（他のオプション）...

.* (7) 個別キーヘルプ（タイトルのみ・本文は KEYL に集約）
:HELP NAME='XXX/KF1'.F1=ヘルプ - ヘルプ
:EHELP.
:HELP NAME='XXX/KF3'.F3=終了 - ヘルプ
:EHELP.
.* ...（他のキー）...

:EPNLGRP.

ヘルプID 設計早見表

ヘルプID 本文 :XH3. 見出し 参照元タグ
XXX/MAIN あり（パネル概要 + 列説明） :XH3.列の説明 PANEL HELP=
XXX/KEYL あり（全キー説明） :XH3.機能キー KEYL HELP=
XXX/HOPT あり（全オプション説明） :XH3.オプション LISTCOL HELP=
XXX/HFIL 〜 HCPY なし（タイトルのみ） なし LISTCOL HELP=
XXX/OPT2 〜 OPT14 なし（タイトルのみ） なし LISTACT HELP=
XXX/KF1 〜 KPGUP なし（タイトルのみ） なし KEYI HELP=
XXXC あり（コマンドプロンプト概要） なし CMD の HLPID=
XXXC/PARM あり（パラメーター説明） なし CMD の HLPPNLGRP=

8. コンパイルと確認手順

コンパイルコマンド

QSYS/CRTPNLGRP PNLGRP(MAI/WRKMSPLF)
               SRCFILE(MAIV300S/QPNLSRC)
               SRCMBR(WRKMSPLF)
               OPTION(*EVENTF)
               AUT(*EXCLUDE)
コンパイル前の必須手順 5250 画面で WRKMSPLF（パネルグループを使うプログラム）を開いている場合は F3 で必ず終了してからコンパイルすること。 オブジェクトがロックされていると CPF5C25（オブジェクト使用中）エラーになる。

5250 での動作確認手順

確認項目 操作 期待結果
全体ヘルプ表示 コマンドライン（===>）にカーソルを置き F1 パネルタイトル → 列の説明 → オプション → 機能キー の順に表示
見出し高輝度確認 全体ヘルプをスクロール 「列の説明」「オプション」「機能キー」が高輝度で1回ずつ表示
OPT コンテキストヘルプ OPT 列にカーソルを置き F1 「オプション (OPT) - ヘルプ」タイトル＋オプション本文が表示
列コンテキストヘルプ ファイル列などにカーソルを置き F1 「ファイル (FILE) - ヘルプ」タイトルが表示（本文は全体ヘルプで確認）
コマンドプロンプトヘルプ コマンド行で WRKMSPLF と入力し F4 → F1 WRKMSPLFC ヘルプが表示

コンパイル警告の見方

メッセージID 重大度 内容 対処
CPD5AD8 10（警告） HELP タグのタイトルテキストが36桁超（切り捨てられる可能性） 無視可。日本語タイトルは36桁超になりがち
CPD5BCB 10（警告） CCSID 変換エラー（システムメッセージ検索時） 無視可。日本語環境での既知警告
CPD5B80 00（通知） DEPTH='*' が具体的な行数に解決された 無視可
CPD5A8C 30（エラー） タグ使用エラー（:SL. など不正タグ） 要修正。対象タグを :XH3. または正しいタグに変更
CPC5A01 — パネルグループが正常に作成された 成功メッセージ

9. よくあるエラーと対処

症状 原因 対処
全体ヘルプで「オプション」が2回表示される MAIN に :IMHELP NAME='…/HOPT'. が残っている その :IMHELP 行を削除する（LISTCOL が自動連結するため不要）
F1 で全体ヘルプではなくコンテキストヘルプが表示される カーソルがコマンドライン以外（OPT 列など）にある コマンドライン（===>）にカーソルを置いてから F1
見出しが高輝度にならない（普通テキストで表示） :SL. や :P. など見出し以外のタグを使っている :XH3. タグに変更する
CPD5A8C コンパイルエラー HELP テキスト内で使用不可のタグ（:SL. 等）を使っている 対象行を確認し正しいタグ（:XH3. / :PARML. 等）に変更
コンパイルは通るがヘルプが表示されない ヘルプIDの綴りが PANEL/LISTCOL/KEYL の HELP= と不一致 ヘルプID の大文字・スラッシュ区切りを完全一致させる
CPF5C25（オブジェクト使用中）でコンパイル失敗 5250 画面でパネルグループを使うプログラムが開いている F3 でプログラムを終了してからコンパイルする
SRCPF の行が 80 バイトで切れて内容が欠ける QPNLSRC の SRCDTA 列は最大 80 バイト。日本語は 1 文字 2 バイト 1行あたり日本語約 40 文字以内に収める。続きは次の行に分割
参考：WRKMSPLF.PNLGRP での実例 本ノウハウは MAI/400 プロジェクトの MAIV300S/QPNLSRC/WRKMSPLF.PNLGRP 開発時に検証・確認したもの。IBM i 7.5、QCCSID 5035 (Japanese EBCDIC) 環境。
