1. 機能概要

SRCTOMAIL は、IBM i (AS/400) の物理ソースファイルまたは通常の物理ファイルのメンバーを読み込み、 その内容をメール本文として SMTP プロトコルでメール送信する ILE C プログラムです。 SMTP サービスプログラム (SMTPSRV / SMTPSRVS) を内部で呼び出して実際の通信を行います。

主な機能は以下のとおりです。

  • ソースファイルメンバー / データファイルメンバーのメール本文送信
  • MIME マルチパートによる IFS ファイル添付
  • To / Cc / Bcc / Reply-To ヘッダー対応（各最大 300 件）
  • EBCDIC → JIS / Shift-JIS / EUC / ASCII 文字コード変換 (iconv)
  • カタカナ SBCS ↔ DBCS 変換オプション
  • SMTP 認証 (PLAIN / LOGIN) 対応
  • STARTTLS / SSL (GSKit DCM) による暗号化通信対応
  • 送信アドレス検証、診断メッセージ通知

6. 内部関数

main(int argc, char *argv[])

プログラムのエントリーポイント。パラメーター受け取りから SMTP 送信完了までの一連の処理を制御する。

int setObjName(void)

グローバル変数 ifsname から IFS パスの最後のパスコンポーネント（ファイル名）を取り出し、objname にセットする。
戻り値: ファイル名の長さ（0 のときはファイル名が空）。(v2.14 追加)

int EdtName(char *lib, char *fil, char *mbr, char *name)

ライブラリ名・ファイル名・メンバー名を結合して、_Ropen で使用できる LIB/FILE(MBR) 形式の文字列を生成する。
EBCDIC のブランク (0x40) と特殊値 * を考慮して整形する。
戻り値: 生成した文字列の長さ。

void DspSTSMSG_ID(char *msgid, void *msgdata, int msgdata_len)

MAIMSG メッセージファイルのメッセージを *STATUS として *EXT キューに送信する。デバッグモード時は *DIAG にも送信する。

void DspDIAGMSG_ID(char *msgid, void *msgdata, int msgdata_len)

メッセージを *DIAG として送信する。処理は継続する。

void DspESCMSG_ID(char *msgid, void *msgdata, int msgdata_len)

ファイルをクローズしてからメッセージを *ESCAPE として送信し、exit(0) でプログラムを終了する。

void DspEXTMSG_ID(char *msgid, void *msgdata, int msgdata_len)

ファイルをクローズしてから診断メッセージ (*DIAG) を送信し、exit(0) で終了する。添付ファイルエラー時に使用。(v2.16 追加)

void DspINFOMSG_ID(char *msgid, void *msgdata, int msgdata_len)

メッセージを *INFO として *EXT キューに送信する。例外ハンドラーや送信完了後の通知に使用。(v3.01 追加)

void _handler(void)

例外ハンドラー。#pragma exception_handler で MAI9899 *ESCAPE のみをハンドルするために登録。mai9899_caught フラグを 1 にセットして DspINFOMSG_ID("MAI9899") を呼び出す。(v3.01 変更)

11. エラー処理方針

  • 致命的エラー（ファイルオープン失敗・DCM 登録失敗・レコード 0 件）は DspESCMSG_ID により *ESCAPE メッセージを送信してプログラムを終了する。
  • 添付ファイルエラーは DspEXTMSG_ID により *DIAG を送信し exit(0) で終了する（呼び出し元ジョブには *ESCAPE は発生しない）。
  • 不正なメールアドレスは DspDIAGMSG_ID により診断メッセージを通知し、そのアドレスをスキップして処理を継続する。
  • #pragma exception_handler により CPF9898 *ESCAPE をハンドルする。ハンドラー _handler() は何もせず return する。

14. 特記事項

  • ソースファイルメンバーを読み込む場合、先頭 12 バイト（シーケンス番号 6 + 日付 6）はスキップしてメール本文に含める。
  • IFS 添付ファイルのファイル名は、setObjName() 内で IFS パスの最後の / 以降の文字列を取り出すことで決定する。漢字ファイル名も対応 (v2.07)。
  • SMTP ポート 465 (SSL) を使用する場合、SMTPRegDCM で GSKit DCM アプリケーション ID を登録してから接続する。
  • SMTP 認証 (SMTPUSR != *NONE) の場合は SMTPSendAuth を呼び出す。
  • TO / CC / BCC の最初のアドレスには "To: " / "Cc: " / "Bcc:" プレフィックスを付与し、2 件目以降は 4 スペースのインデントで継続行として出力する。
  • バッファーサイズは最大 32,767 バイト（buf[32767]）であり、32,767 バイトを超えるレコード長には対応していない。
  • #pragma exception_handler は MAI9899 *ESCAPE のみをハンドル対象とする（第5・第6引数で限定）。捕捉後は mai9899_caught フラグをセットし、main() 末尾で DspINFOMSG_ID("MAI9899") を再送信する。(v3.01)
  • すべての本番オブジェクト (PGM / SRVPGM / CMD / PNLGRP) は MAI ライブラリに配置し、オーナーは QPGMR に変更する。
